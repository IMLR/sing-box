# AX3600 定制内核

2026-10-10：基于 reF1nd 稳定版 `v1.14.2-reF1nd`，源码修订
`7c1ffd271cbc84fed23eaabdcd7e1cefb42a778e`。

沿用原有唯一功能补丁：`third_party/sing/common/bufio/splice_linux.go`
的 `maxSpliceSize` 从 `1 << 20` 调整为 `64 << 10`，避免 Linux 4.4
路由器在长期运行、内存碎片严重时扩容 splice 管道产生高阶内存分配。
零拷贝仍然启用。

完整模块源码；除上述一行外没有修改。不能继续使用旧版 v0.8.2。

构建工作流 `.github/workflows/ax3600-core.yml` 使用 Go 1.26.8、CGO=0，
构建标签与旧路由器内核一致。显式写入版本 `1.14.2-reF1nd-ax3600-hyfix1`，
避免 ShellCrash 读到 unknown。产物包括 ARM64 原始文件、UPX 文件、
同源码同标签 AMD64 校验文件及 SHA256SUMS。
